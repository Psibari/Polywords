# POLYWORDS Game Feel Framework

## Goal

Make every meaningful action feel immediate, readable, satisfying, and emotionally connected to the puzzle decision.

## Input

Audit:
- touch-down acknowledgement
- hold acquisition
- drag ownership
- intentional-swipe threshold
- accidental movement tolerance
- direction locking
- cancellation behavior
- release behavior
- input during overlays
- repeated-gesture fatigue

## Motion

Audit:
- anticipation
- acceleration and deceleration
- continuity from finger to animation
- destination clarity
- overshoot and settle
- object weight
- blocking time
- recovery time
- state-transition continuity
- reduced-motion behavior

## Feedback Stack

For each action map:
- visual feedback
- sound feedback
- haptic feedback
- Polly reaction
- score/progression feedback
- state change

These should reinforce one interpretation, not compete.

## Emotional Contrast

Mastered, Haunted, Banished, trap selection, and ordinary progression must feel distinct.

Success should not merely be failure with a greener particle effect. Failure should be clear without humiliating the player.

## Timing Questions

- How quickly does the game acknowledge intent?
- How long until control returns?
- Is any animation attractive but interaction-blocking?
- Does repetition make the timing exhausting?
- Does suspense increase payoff or merely delay it?
- Can the player understand the result before the next input?

## Device and Context Checks

- lower-end device performance
- small-screen readability
- one-handed reach
- sound-off clarity
- haptics-off clarity
- interruptions and app resume
- reduced motion
- low battery/performance modes when relevant

## Game Feel Failure Conditions

Flag when:
- the player is unsure whether input registered
- the object does not feel attached to the finger
- the animation finishes after the emotional moment has passed
- sound and visual impact disagree
- input remains locked without clear reason
- failure feels punitive rather than informative
- repeated effects become exhausting
- important actions feel weightless
