# POLYWORDS Content Philosophy

POLYWORDS wakes up meanings players already know. It does not teach definitions.

Every REAL should move through hesitation (“What is this?”), recognition (“Of course”), and
satisfaction (“I knew that”). Write from ordinary memory—paychecks and riverbanks for BANK,
campfires and sports for MATCH—not dictionary labels.

A trap activates the nearby wrong memory first. It must tempt an experienced speaker but lose
honestly; the player should blame the rushed choice, never the writing.

Each word may live in a different world. Do not force one clever formula across the bank.
North star: “Wait… Oh. Right.”
