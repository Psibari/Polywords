# POLYWORDS Content Philosophy

POLYWORDS is a recognition game, not a vocabulary lesson. Players already know the
meanings; the game wakes up memories they did not realize were connected.

Every REAL should create:

1. hesitation — “What is this talking about?”
2. recognition — “Of course.”
3. satisfaction — “I knew that.”

Write from where a meaning lives in ordinary life: paychecks and riverbanks for BANK,
campfires and sports for MATCH, gardens and family history for ROOT. A REAL is a familiar
memory trigger, never a compressed definition.

A trap triggers the nearby wrong memory first. It must be close enough to tempt an
experienced speaker, but wrong enough to lose honestly. The player should blame the rushed
choice, never the writing.

Every word may draw from a different world—school, work, sports, childhood, medicine,
internet culture. Do not force one clever formula across the database.

North star: reveal the network of meanings people have used all their lives. The feeling is
“Wait… Oh. Right.”, not “I learned a definition.”
